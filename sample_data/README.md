# Sample Datasets for DBGuard Demonstrations

This directory contains synthetic datasets generated by `scripts/create_test_exports.py` specifically designed to test and demonstrate edge cases and the central problem statement:

1. `demo_a_baseline_100k.csv.gz`:
   - 100,000 records
   - Normal entropy distribution
   - Compressed size: ~3,092,707 bytes (~3.09 MB)
   - Baseline for comparative analysis

2. `demo_a_repetitive_130k.csv.gz`:
   - 130,000 records (+30% rows)
   - Highly repetitive categorical data (Operations, Enterprise, ACTIVE, standard recurring text)
   - Compressed size: ~385,343 bytes (~385 KB, -87.5% smaller!)
   - **Directly reproduces the official problem statement** where a larger dataset compresses to a substantially smaller file.

3. `demo_b_truncated.csv.gz`:
   - Sliced at 45% of baseline stream without gzip trailer.
   - Tests detection of physical stream truncation (`TruncatedStreamError`).

4. `demo_c_incomplete_85k.csv.gz`:
   - 85,000 rows in valid gzip container.
   - Paired with `manifests/demo_c_incomplete_85k.manifest.json` which expects 100,000 rows.
   - Tests detection of logical incompleteness in a valid compressed stream.

5. `demo_e_matching_25k.csv.gz`:
   - 25,000 rows with synchronously generated manifest.
   - Tests matching trusted manifest (`VERIFIED_WITHIN_SCOPE`).

6. `demo_f_tampered_25k.csv.gz`:
   - 25,000 rows with modified values.
   - Demonstrates detection of content tampering via cryptographic stream and chunk hashes.

7. `test_malformed.csv.gz`:
   - Contains rows with inconsistent column counts and unescaped quotes.
   - Tests `RECOVERY_POSSIBLE_WITH_ERRORS` classification.
